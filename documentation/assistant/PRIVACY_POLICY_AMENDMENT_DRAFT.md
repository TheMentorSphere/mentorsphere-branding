# Draft Privacy Policy addition for owner review

Status: draft only. Do not publish or enable the assistant publicly until approved.

## Website assistant

The MentorSphere website may provide an optional MentorSphere Assistant to help visitors find approved information about services, pricing, booking and policies.

When a visitor sends a message, the message and a limited amount of the current conversation are sent through The MentorSphere's Cloudflare-hosted website service to OpenAI so that a short response can be generated from selected MentorSphere information. The assistant is not connected to client records, email, calendars, bookings or payment systems. It does not accept file uploads.

Chat messages are used only to provide the response during the active browser session. The MentorSphere does not store raw chat transcripts in its own database, browser local storage or cookies, and does not use messages for marketing. The interface keeps limited conversation context temporarily in browser memory and clears it when the page is closed or refreshed.

The OpenAI API request is configured with response storage disabled. OpenAI states that API data is not used to train its models unless the customer explicitly opts in. Unless The MentorSphere's OpenAI organisation has approved Zero Data Retention or Modified Abuse Monitoring controls, OpenAI may retain prompts and responses in abuse-monitoring logs for up to 30 days. Processing location depends on the OpenAI account and data-residency configuration in use. The standard global API may process data outside the United Kingdom. OpenAI should be listed as a service provider and sub-processor before the assistant is made public.

Cloudflare processes the website request and may process technical information such as IP address, browser information, security events and diagnostic logs under the existing website-hosting and security arrangements. The MentorSphere records limited anonymous assistant events such as chat opened, message sent, fallback shown, source link clicked, helpful rating and technical error. These events do not include the visitor's message text.

Visitors should not enter names, contact details, dates of birth, diagnoses, medical records, identification information, EHCPs, assessment reports or detailed safeguarding information in the assistant. The assistant does not provide clinical, diagnostic, therapeutic, legal, safeguarding-assessment or emergency advice. It is not monitored. In immediate danger, call 999 and use the appropriate emergency or safeguarding route.

The lawful basis, provider contract, international-transfer mechanism, retention configuration and final sub-processor wording must be confirmed by the data controller before publication.
