# The MentorSphere website rebuild

This branch contains the complete static rebuild of The MentorSphere website.

The production-ready site is in `docs/` for GitHub Pages deployment. It includes 16 pages, responsive layouts, accessible navigation, policy pages, structured metadata, a sitemap and The MentorSphere's established branding.

## Deployment

After review and merge, enable GitHub Pages from the `main` branch and `/docs` folder. The existing website and DNS should remain unchanged until the replacement has been reviewed and approved.
