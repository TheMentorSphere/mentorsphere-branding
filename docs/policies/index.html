Using these documents

Website versions make the full wording easier to use

The policy pages reproduce the substantive wording of the current published documents in a more accessible web format. A PDF copy can be requested directly while the document set is reviewed and brought up to date.

Where a current pricing page and an older policy document show different figures, the latest price confirmed in writing before booking will apply.

Questions are welcome

  • Ask how a policy applies before booking.
  • Request a reasonable adjustment to communication or delivery.
  • Raise a safeguarding or privacy concern directly with Luke Turner.
  • Request confirmation of the current document version.
